# Гайд По 3D-Ассетам

Статус: draft 0.1

Этот документ фиксирует требования к 3D-ассетам для мобильной low-poly fantasy игры. Его цель - сделать так, чтобы башни, враги, окружение и эффекты выглядели цельно, читались с камеры 3/4 top-down и не перегружали Android-устройства.

## 1. Общий Стиль

- Основной стиль: low-poly fantasy, средневековье.
- Враги: зомби, скелеты, нежить и близкие fantasy-существа.
- Камера: 3/4 top-down orthographic camera, поэтому силуэт важнее мелких деталей.
- Модели должны хорошо читаться сверху и под углом, а не только с фронтального вида.
- Башни должны иметь узнаваемый силуэт, понятный грейд и читаемую точку атаки.
- Враги должны отличаться формой, размером, цветовым акцентом или анимацией.

Главное правило: если деталь не видна на телефоне во время боя, она не должна стоить дорого по полигонам, текстурам или материалам.

## 2. Форматы

Рекомендуемые форматы моделей:

- `.fbx` - основной рабочий формат для Unity.
- `.glb` / `.gltf` - допустимо, если модель корректно импортируется и материалы легко пересобираются в Unity.
- `.blend` лучше не использовать как основной формат в проекте; предпочтительно экспортировать в `.fbx`.

Рекомендуемые форматы текстур:

- `.png` - основной вариант для hand-painted/low-poly текстур и прозрачности.
- `.tga` - допустимо для рабочих текстур, если удобно в пайплайне.
- `.jpg` - только для текстур без прозрачности и без необходимости высокого качества краёв.

В Unity финальное сжатие текстур настраивается через import settings, а не через ручное пережатие исходников.

## 3. Текстуры

Базовые размеры текстур:

- мелкие props и снаряды: 256x256 или 512x512;
- обычные враги: 512x512;
- важные враги, мини-боссы, боссы: 1024x1024;
- башни: 512x512 или 1024x1024;
- крупные элементы окружения: 1024x1024;
- UI-иконки: отдельно, по UI-гайду.

Для первого этапа лучше считать 1024x1024 верхней границей для большинства gameplay-ассетов. 2048x2048 использовать только для очень важных крупных объектов, если они реально видны в кадре.

Желательный набор текстур для 3D-модели:

- Base Color / Albedo;
- Normal, если он действительно добавляет читаемость;
- Metallic, если есть металл;
- Roughness или Smoothness, если это нужно материалу;
- Emission только для специальных эффектов.

Для low-poly стиля часто достаточно Base Color и простого материала. Normal/Metallic/Roughness добавляем только там, где это заметно в игре.

## 4. Материалы

- Для обычного ассета стремимся к 1 материалу.
- Для сложного босса или крупного здания допустимо 2-3 материала.
- Не плодим уникальные материалы без необходимости.
- По возможности объединяем мелкие текстуры в atlas.
- Материалы должны быть совместимы с URP.
- Для базовых объектов используем URP/Lit или простой проектный shader, если позже появится единый стиль.

На мобильных устройствах количество материалов и draw calls часто важнее, чем само количество полигонов.

## 5. Ориентиры По Полигонам

В Unity удобнее смотреть на triangles, потому что именно они ближе к реальной стоимости отрисовки.

Ориентиры для первого production-friendly этапа:

| Тип ассета | Рекомендуемо | Верхняя граница на старте |
| --- | ---: | ---: |
| Снаряд | 50-300 triangles | 500 triangles |
| Мелкий prop | 100-800 triangles | 1 000 triangles |
| Обычная башня | 500-1 500 triangles | 2 500 triangles |
| Башня высокого грейда | 1 500-3 500 triangles | 5 000 triangles |
| Обычный враг | 800-2 000 triangles | 3 000 triangles |
| Крупный враг / elite | 2 000-4 000 triangles | 6 000 triangles |
| Мини-босс | 4 000-8 000 triangles | 10 000 triangles |
| Босс | 8 000-15 000 triangles | 20 000 triangles |
| Небольшой объект окружения | 100-800 triangles | 1 500 triangles |
| Крупный объект окружения | 1 000-4 000 triangles | 6 000 triangles |
| Замок / база | 3 000-8 000 triangles | 12 000 triangles |

Эти цифры - не закон, а рабочие ограничения для мобильной игры. Если ассет выходит за верхнюю границу, нужно понимать, зачем это нужно, насколько часто он виден и сколько таких объектов одновременно находится в кадре.

Особенно важно:

- обычных врагов на экране может быть много, значит они должны быть дешевле;
- башен на поле может быть до 25, значит базовые грейды должны быть экономными;
- снарядов может быть много одновременно, значит они должны быть очень простыми;
- босс может быть тяжелее, потому что обычно он один.

## 6. Масштаб И Pivot

- Единица Unity: 1 unit примерно равен 1 метру.
- Pivot башни: снизу по центру, чтобы башня точно вставала на клетку.
- Pivot врага: снизу по центру, в районе точки контакта с землёй.
- Pivot снаряда: в центре или в точке, удобной для полёта.
- Модель должна импортироваться без странного масштаба вроде `0.01` или `100`, если это можно исправить на этапе экспорта.
- Перед импортом желательно применить transform в 3D-редакторе.

Для башен важно, чтобы визуальная ширина соответствовала занимаемым клеткам. Базовое правило: одна башня занимает одну клетку.

## 7. Читаемость С Камеры

Ассет считается подходящим, если он:

- узнаётся в портретном кадре телефона;
- не перекрывает путь врагов критически важной частью модели;
- имеет читаемый силуэт без приближения камеры;
- отличается от других ассетов не только мелкими деталями;
- не требует рассматривать текстуру вплотную.

Для башен грейды должны отличаться хотя бы одним заметным элементом: высота, форма крыши, оружие, цветовой акцент, эффект или размер.

## 8. Анимации

Для врагов минимальный набор на будущее:

- `Idle`;
- `Walk`;
- `Hit`;
- `Attack`, если враг атакует замок или башню;
- `Death`.

Для первого прототипа можно обойтись без анимаций и двигать врага кодом. Но при заказе или генерации ассета лучше сразу проверять, есть ли rig и базовые анимации.

Требования:

- один понятный root;
- без лишних костей, которые не участвуют в анимации;
- короткие loop-анимации должны бесшовно повторяться;
- death-анимация не должна уводить модель далеко от pivot.

## 9. Коллайдеры И Gameplay-Точки

Модель сама по себе не обязана иметь финальные коллайдеры. В Unity мы добавляем gameplay-обвязку через prefab.

Для башни в prefab нужны:

- простой collider для выбора;
- `FirePoint` - точка выстрела;
- возможная точка для VFX;
- корректная посадка на клетку.

Для врага в prefab нужны:

- простой collider или CharacterController;
- точка для HP bar над головой;
- точка центра для попаданий;
- при необходимости attack point.

Сложные mesh-colliders для обычных gameplay-объектов не используем.

## 12. Проверка Перед Добавлением

Перед тем как считать ассет готовым, проверяем:

- формат модели подходит для Unity;
- модель импортируется без ошибок;
- масштаб адекватный;
- pivot находится в правильном месте;
- текстуры подключаются к URP-материалу;
- количество triangles не выходит за ориентир без причины;
- модель читается с камеры 3/4 top-down;
- ассет не содержит лишних материалов;
- для врага есть или запланированы нужные анимации;
- prefab можно использовать в gameplay без ручной починки каждый раз.
